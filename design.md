# Design System - Iqbal Dwi Fathonah Portfolio

## 1. Core Vibe
- Clean, Analytical, Professional, Modern Minimalist.
- High-contrast layout prioritizing intentional whitespace rather than heavy decorative borders or drop-shadows.
- Zero AI-generated illustration cliches, zero heavy 3D gradients, zero visual clutter.

## 2. Color Palette
- **Base Background**: `#FAFAFA` (`bg-neutral-50`)
- **Primary Text / Headings**: `#171717` (`text-neutral-900`)
- **Secondary Text**: `#525252` (`text-neutral-600`)
- **Navbar Background**: `#F5F5F5` (`bg-neutral-100/80` with `backdrop-blur-md`)
- **Primary Button ("View Projects")**: Solid black `#171717` (`bg-neutral-900 text-white`)
- **Secondary Button ("Resume")**: Subtle neutral outline (`bg-neutral-100 text-neutral-800 border-neutral-200`)
- **Data Accent Tags**:
  - Background: `#DBEAFE` (`bg-blue-100`)
  - Text: `#1E3A8A` (`text-blue-900`)

## 3. Typography
- **Headings (H1/H2)**: Classic editorial serif (`font-serif`: *Newsreader*, *Playfair Display*, *Georgia*).
- **Body & Captions**: Clean modern sans-serif (`font-sans`: *Inter*, system UI).
- **Technical Metrics / Labels**: Monospace font (`font-mono`) with uppercase tracking.

## 4. UI Components & Layout
- **Navbar**: Center-aligned floating pill (`rounded-full`), frosted glass effect (`backdrop-blur-md`).
- **Buttons**: Pill-shaped (`rounded-full`), generous padding (`px-6 py-2.5`), smooth micro-transitions.
- **Cards**: Minimalist `1px` border (`border-neutral-200`), rounded corners (`rounded-2xl`), subtle hover state.
- **Projects**: Dedicated thumbnail placeholder area (`bg-neutral-200 h-56`) with technical case study markers.
